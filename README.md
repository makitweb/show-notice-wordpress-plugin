## ⬇️ Download Code

Each episode folder contains the plugin code **as it was at the end of that video** — so you can follow along exactly.

**Download a specific episode:**
Go to [Releases](../../releases) → find the release tagged `part-01` (or whichever episode you need) → download the zip.

**Browse the latest code:**
The most recent episode's code is always in the highest-numbered folder.

---

## 🔧 How to Use

1. Download the zip for the episode you're watching.
2. Extract it — you'll get a `show-notice` folder.
3. Upload the `show-notice` folder to `wp-content/plugins/` on your WordPress site.
4. Go to **Plugins → Installed Plugins** and activate **Show Notice**.

---

## 📌 About This Series

This series is designed for WordPress developers who want to learn plugin development from the ground up using PHP and WordPress APIs.

**Topics covered across the series:**
- WordPress Plugin Header & activation hooks
- Shortcode API
- Settings API (`register_setting`, `add_settings_section`, `add_settings_field`)
- Admin menus (`add_menu_page`, `add_submenu_page`)
- Database (`$wpdb`, `dbDelta()`)
- `WP_List_Table` for custom admin tables
- Nonces, capability checks, and data sanitization
