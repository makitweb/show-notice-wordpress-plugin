# Part 06 – How to Create a Custom Admin Table Using WP_List_Table

📺 **Watch the video:** https://youtu.be/Keq7SHAM2-A

---

## What You'll Learn

- Load the WordPress `WP_List_Table` class
- Create a custom list table class
- Define table columns using `get_columns()`
- Fetch database records using `$wpdb`
- Display notice data in the WordPress admin area
- Add an **All Notices** submenu to a custom admin menu

---

## How to Use This Code

1. Download or copy the `show-notice` folder from this episode.
2. Upload it to `wp-content/plugins/` on your WordPress site.
3. Go to **Plugins → Installed Plugins** and activate **Show Notice**.
4. Go to **Show Notice → All Notices** in the WordPress admin sidebar to see the notices table.
