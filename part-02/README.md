# Part 02 – How to Add a Settings Page to a WordPress Plugin

📺 **Watch the video:** https://youtu.be/rwNotHc3ggI

---

## What You'll Learn

- Create a settings page under the WordPress Settings menu
- Use `add_options_page()` to register a settings page
- Register plugin settings with `register_setting()`
- Add settings sections and fields
- Create a text field and dropdown menu
- Use `get_option()` to retrieve saved settings
- Sanitize input and escape output
- Update a WordPress shortcode to use saved settings

---

## How to Use This Code

1. Download or copy the `show-notice` folder from this episode.
2. Upload it to `wp-content/plugins/` on your WordPress site.
3. Go to **Plugins → Installed Plugins** and activate **Show Notice**.
4. Go to **Settings → Show Notice** to configure the notice message and type.
