# Part 04 – WordPress Plugin Development: Create Custom Submenu Pages

📺 **Watch the video:** https://youtu.be/tMM0QupdHKg

---

## What You'll Learn

- How to use `add_submenu_page()` in WordPress
- How to connect submenu pages to a custom admin menu
- How to set page titles, menu titles, capabilities, and menu slugs
- How to use callback functions to display submenu page content
- How to create a Help page with a shortcode example
- How to link to the plugin's Settings page using `admin_url()`
- How to safely output a URL using `esc_url()`

---

## How to Use This Code

1. Download or copy the `show-notice` folder from this episode.
2. Upload it to `wp-content/plugins/` on your WordPress site.
3. Go to **Plugins → Installed Plugins** and activate **Show Notice**.
4. Find the **Show Notice** menu in the admin sidebar — it now has **Settings** and **Help** submenus.
