# Part 03 – How to Add a Custom Admin Menu in WordPress Plugin

📺 **Watch the video:** https://youtu.be/xVqQwGatCqw

---

## What You'll Learn

- How to add a custom admin menu in WordPress
- How to use `add_menu_page()` in plugin development
- The parameters of `add_menu_page()`
- How to add a WordPress admin menu icon using Dashicons
- How to change the menu icon
- How to control the menu position
- The difference between `add_options_page()` and `add_menu_page()`

---

## How to Use This Code

1. Download or copy the `show-notice` folder from this episode.
2. Upload it to `wp-content/plugins/` on your WordPress site.
3. Go to **Plugins → Installed Plugins** and activate **Show Notice**.
4. Find the **Show Notice** menu item in the WordPress admin sidebar.
