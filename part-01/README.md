# Part 01 – How to Create a WordPress Plugin from Scratch

📺 **Watch the video:** https://youtu.be/cOGUgyS-BOQ

---

## What You'll Learn

- How to create a WordPress plugin from scratch
- How to create a plugin folder and PHP file
- How to add a WordPress plugin header
- How to activate your custom plugin
- How to create a custom shortcode using `add_shortcode()`
- How to write a PHP callback function for the shortcode
- How to display a notice on any page or post using `[show_notice]`

---

## How to Use This Code

1. Download or copy the `show-notice` folder from this episode.
2. Upload it to `wp-content/plugins/` on your WordPress site.
3. Go to **Plugins → Installed Plugins** and activate **Show Notice**.
4. Add the shortcode `[show_notice]` to any page or post.
