# Part 07 – How to Add a Custom Form in WordPress Admin

📺 **Watch the video:** https://youtu.be/-98osdP_nEQ

---

## What You'll Learn

- How to add a submenu page in WordPress admin
- How to create a custom admin form using PHP
- How to use WordPress form fields and the submit button
- How to protect form submissions with a nonce
- How to check user permissions with `current_user_can()`
- How to sanitize and validate form data
- How to insert records into a database using `$wpdb->insert()`
- How to redirect users after a successful submission

---

## How to Use This Code

1. Download or copy the `show-notice` folder from this episode.
2. Upload it to `wp-content/plugins/` on your WordPress site.
3. Go to **Plugins → Installed Plugins** and activate **Show Notice**.
4. Go to **Show Notice → Add New** in the WordPress admin sidebar to use the form.
